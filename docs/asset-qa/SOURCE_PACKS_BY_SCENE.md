# Worst Date Ever — asset sources mapped to each scene

**Checked source pages: 2026-11-26.** These links lead to artist/model library pages or particular model listings. A listed pack is **a place to look**, not proof that it contains every required named prop. Download and inspect files individually; keep downloaded license text, filename, URL and checksums. Check specific third-party pack terms again at download time. The `inventories/catalog.csv` lists all 265 requirements and their search/source suggestions.
