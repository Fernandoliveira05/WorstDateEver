# Logs

Esta pasta guarda o que cada integrante do grupo aprendeu ao final de cada aula. É um diário individual de aprendizado, e não um relatório do projeto (as decisões do grupo ficam no `README.md` da raiz e em `docs/`).

## Estrutura

```
Logs/
├── Fernando/
├── Pietra/
├── Isadora/
├── Leonardo/
└── Ian/
```

Cada pessoa escreve apenas na sua própria pasta.

## Como nomear os arquivos

Um arquivo por aula, no formato `AAAA-MM-DD.md`, usando a data da aula.

Exemplo: `Logs/Fernando/2026-11-16.md`

## Modelo de registro

Copie o modelo abaixo para um novo arquivo a cada aula.

```markdown
# Aula de DD/MM/AAAA

## O que aprendi
-

-

-

-
```
