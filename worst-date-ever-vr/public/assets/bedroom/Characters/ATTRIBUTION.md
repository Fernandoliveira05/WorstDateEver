# Character assets

The ten character models are by Quaternius and use [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Source packs: [Ultimate Modular Men](https://quaternius.com/packs/ultimatemodularcharacters.html) and [Ultimate Modular Women](https://quaternius.com/packs/ultimatemodularwomen.html).

The Unity copies use softened surface normals and matte material settings.

## Corridor creature

`CorridorCreature.glb` is adapted from Grab3D's [Horror Monster](https://grab3d.com/models/creatures/horror-monster/).
The original is AI-assisted and released under [CC0 1.0](https://grab3d.com/dl/horror-monster/LICENSE.txt).
The browser copy uses a reduced mesh with the original textures removed. The game applies the corridor lighting material.
