# iClona and picnic benchmark

The tracked files contain runnable models, licenses, input catalogs, and QA tooling. Screenshots, capture indexes, generated reports, and duplicate publisher downloads are local outputs. To rebuild the original source binaries, download the files named in the publisher manifests into the corresponding source directories.

The supplied bedroom and picnic concepts set the visual direction. The existing browser bedroom and its approved reference direction were used as the comparison baseline. Project assets already in use have no separate recorded production sign-off in `assets/style-baseline.json`.

Four publisher models are stored under `sources/` with their accompanying licenses and publisher manifests. The source archives describe procedural Blender work and AI-assisted scripting. The exact binary and adapted hashes are in `manifest.json`. The phone export comes from the current game shell, frame, and Deu Ruim screen. Its app remains live Canvas UI in the game.

The four picnic candidates are also playable on Caio’s Esquerdo-macho WebXR date for review in context. The development fixture loads one prop at a time for isolated capture. The grip profile uses GLB model coordinates in meters. The blanket morphs at the grabbed seam and the basket lids have separate hinges. The sandwich is a single wrapped half and the kombucha is a single isolated, relabeled bottle. Casting, grabbing, trial rotation, release and re-grab evidence is labeled by the capture harness. In-date availability does not change the independent review verdict or the Quest validation status.

## Reproducing the benchmark

From `worst-date-ever-vr`, with Blender 4.5 LTS or newer and the project’s Node dependencies installed:

```sh
blender -b --python-exit-code 1 -P tools/hand-qa/adapt_picnic.py -- assets/hand-qa
blender -b --python-exit-code 1 -P tools/hand-qa/render_glb_turntable.py -- \
  --model assets/hand-qa/candidates/picnic_basket.glb --asset-id picnic_basket \
  --output assets/hand-qa/evidence/picnic_basket/candidates --resolution 400
blender -b --python-exit-code 1 -P tools/hand-qa/audit_glb.py -- assets/hand-qa
WDE_QA_CAPTURE_REVISION=webxr-rework-6 node tools/hand-qa/serve.mjs
```

Open a fixture at `http://localhost:4190/` in Chromium. A browser automation harness can call the following expression once the page loads.

```js
await (await import('/tools/hand-qa/capture.js')).captureBenchmark(console.log);
```

The versioned capture exports the phone GLB alongside its screenshots. Use that GLB for the neutral turntable so both sets identify the same model revision. Build an indexed review packet with all 48 approaches before asking the independent reviewer to score it.

```sh
python tools/hand-qa/review_packet.py picnic_blanket \
  --capture-revision webxr-rework-6 --isolated-revision candidates-rework-3 \
  --model assets/hand-qa/candidates/picnic_blanket.glb
```

The manifest accepts an independent review only when the report is filed under the selected capture revision and names the matching candidate hash.

```sh
node tools/hand-qa/manifest.mjs
python tools/hand-qa/catalog_status.py
npm test
```
