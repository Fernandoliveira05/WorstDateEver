# Sourced date props

CC0 models downloaded during the 2026-11-27 internet-sourcing pass. Source
records and hashes live in `../../assets/hand-qa/sources/<id>/source-record.json`;
the per-asset page/licence is in the same record. The Unity build uses these
models for date props and venue furniture instead of procedural stand-ins.

Some files come from Grab3D CC0 packs (the existing hand-QA basket, blanket,
sandwich, kombucha, sushi set and book); the rest come from 3dassets.dev CC0
packs (Restaurant Kitchen, Cafe Bakery, Bar Pub, Bedroom, Park, Izakaya and
Cyberpunk interiors).
